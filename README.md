# Hành trình học lập trình của tôi

Xin chào! Tôi là một sinh viên đang bắt đầu hành trình lập trình.

## Mục tiêu
- Nắm vững kiến thức lập trình cơ bản
- Học Git và GitHub
- Hoàn thành các dự án cá nhân
- Rèn luyện kỹ năng làm việc nhóm

## Công nghệ đang học
- C / C++ hoặc Python
- HTML, CSS, JavaScript
- Git và GitHub

## Các dự án
- Bài tập lập trình cơ bản
- Dự án cá nhân đầu tiên

## Tiến độ
Tôi sẽ cập nhật repository khi học được
kiến thức mới và hoàn thành dự án.
